## 日报功能优化

### 1. 确认框修复
- **问题**：Tailwind `hidden` 类优先级高于 `style.display`，导致弹窗不显示
- **修复**：改为纯内联样式 `position: fixed; top: 0; left: 0; right: 0; bottom: 0; z-index: 9999`
- **文件**：`frontend/src/components/ConfirmDialog.tsx`

### 2. 日期选择器
- **新功能**：支持选择最近30天任意日期填报/修改日报
- **实现**：点击日期弹出选择框，显示已填报标记
- **历史编辑**：每条历史日报增加"✏️ 编辑"按钮

### 3. 智能解析优化
- **时间段共享**：识别"下午13:45-18:00做了4件事"，工时平均分配而非累加
- **项目匹配**：模糊匹配算法，去掉通用词后提取关键词
- **内容润色**：STAR原则改写（动词开头、结果导向、15-40字）
- **序号分组**：正确识别"4.xxx, yyy"属于同一项
- **时间保存**：从 `ai_parsed_data` 提取时间更新工作项

### 4. 推送服务
- **移除**：凌晨1点的每日摘要推送
- **保留**：早上8点高风险预警、下午4点日报提醒

### 5. 手机端适配
- **日期选择器**：全宽显示、紧凑字体
- **解析结果卡片**：标签换行、文本省略
- **历史日报**：分两行显示、状态标签紧凑、编辑按钮改为图标
