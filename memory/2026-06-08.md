### 最佳解决方案（待实现）

**远程AI服务器组合API**：

在远程AI服务器创建 `/api/search_and_match` 接口：
```python
@app.post("/api/search_and_match")
async def search_and_match_projects(text: str):
    # 1. 本地嵌入计算（nomic-embed-text，毫秒级）
    embedding = ollama.embeddings(model="nomic-embed-text", prompt=text)
    # 2. 本地ChromaDB查询（毫秒级）
    results = collection.query(query_embeddings=[embedding], n_results=10)
    # 3. 关键词过滤
    filtered = keyword_filter(results, text)
    return filtered
```

**优势**：
- 嵌入+检索+过滤都在远程AI服务器本地完成
- 宿主服务器只需单次API调用（frpc穿透1次）
- 总耗时：单次穿透 + 本地计算 ≈ 5-10秒
