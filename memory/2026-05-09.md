## 🔧 登录跳转问题修复

### 问题现象
第一次登录后又跳回登录页，需要登录两次才能成功。

### 根因分析
- zustand persist 中间件异步写入 localStorage
- 登录后 100ms 跳转时，localStorage 可能还没写入完成
- App.tsx 检查 `isAuthenticated()` 时 token 不存在，跳回登录页

### 解决方案
```typescript
// 登录成功后手动同步写入 localStorage
localStorage.setItem('project-agent-storage', JSON.stringify({
  state: { user: userData, token: result.access_token },
  version: 0
}))

// 延长跳转延迟到 300ms
setTimeout(() => navigate('/'), 300)
```

## 🔧 项目权限优化完成

### 需求
- 项目列表：全员可见
- 修改操作：仅项目负责人或管理员可操作

### 修改内容

#### 1. 项目列表API（全员可见）
**文件**: `/backend/app/main.py`

**修改前**：
```python
if role_id == 11:  # 管理员
    # 返回所有项目
else:
    # 只返回自己负责的项目
```

**修改后**：
```python
# 全员可见所有项目
result = conn.execute(text("""
    SELECT id, name, leader, status, project_year FROM projects
    WHERE is_deleted = false ORDER BY project_year DESC, id
"""))
```

#### 2. 权限检查函数
**新增函数**: `check_project_edit_permission(project_id, user_info)`

**权限判断规则**：
- `role_id == 11` → 管理员，有权限
- `user.name == project.leader` → 项目负责人，有权限
- 其他 → 无权限

#### 3. 应用权限检查的操作
| 操作 | API | 权限要求 |
|------|-----|---------|
| 上传计划 | `POST /plans/upload/{project_id}` | 负责人或管理员 |
| 更新任务状态 | `POST /projects/{project_id}/update-task-status` | 负责人或管理员 |

#### 4. 修复JWT token解析问题
**问题**: `verify_token` 返回 `{"username": ...}` 但 `get_current_user` 使用 `payload.get("sub")`

**修复**: 统一使用 `sub` 字段
```python
# 修复前
return {"username": username, "user_id": ...}

# 修复后
return {"sub": username, "user_id": ...}
```
