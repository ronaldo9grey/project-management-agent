### 置信度计算公式

```
综合置信度 = 
    频次置信度 × 0.30    # 出现次数越多越可信
  + 时间衰减 × 0.25      # 近期更重要
  + 用户多样性 × 0.25    # 多用户确认更可信
  + 一致性 × 0.20        # 纠正结果一致性

阈值：
- ≥ 0.85：自动批准
- 0.70-0.85：待审核
- < 0.70：忽略
```

## 📚 技术讨论：BERT微调

### 核心概念

- **预训练**：大规模无监督学习（维基百科33亿词）
- **微调**：特定任务优化（学习率2e-5）
- **双向理解**：同时看左右上下文

### 在项目别名匹配中的应用

```python
from sentence_transformers import SentenceTransformer

model = SentenceTransformer('shibing624/text2vec-base-chinese')
vec_alias = model.encode("炭渣项目")
vec_official = model.encode("铝电解碳渣低温氧化处理技术")
similarity = cosine_similarity([vec_alias], [vec_official])
# 结果: 0.87
```

### 是否需要BERT？

| 数据量 | 建议 |
|--------|------|
| < 100条 | 统计学习足够 |
| 100-1000条 | 向量匹配（不微调） |
| > 1000条 | 可尝试BERT微调 |

## 📚 技术讨论：BERT微调任务类型详解

### 数据量定义澄清

**指的是：历史累计总量**

| 数据量 | 定义 | 来源 |
|--------|------|------|
| < 100条 | 历史累计别名纠正记录 | `project_corrections`表 |
| 100-1000条 | 同上 | 运行1-2年积累 |
| > 1000条 | 同上 | 运行2-3年积累 |

**项目别名场景数据产生速度**：
- 每天：~2条纠正记录
- 每月：~60条
- 每年：~720条
- 达到10000条：约14年

### 一、简单分类任务

**用途**：判断一段文本属于哪个类别

**适用场景**：

| 场景 | 输入 | 输出 | 数据量 |
|------|------|------|--------|
| 情感分析 | 用户评论 | 正面/负面/中性 | 1000+ |
| 新闻分类 | 新闻内容 | 财经/体育/娱乐 | 2000+ |
| 垃圾邮件 | 邮件内容 | 垃圾/正常 | 500+ |
| 意图识别 | 用户query | 查询/投诉/咨询 | 1000+ |

**案例：电商评论情感分析**
```
输入："这件衣服质量很好，物流也快，下次还会来买！"
     ↓
BERT分类
     ↓
输出：正面情感 (置信度: 0.92)

训练数据：
- 10万条评论 × 0.1元 = 1万元
- GPU训练：100元
- 总成本：约1.5万元
- 训练周期：1周
- 准确率：95%
```

**案例：银行客户意图识别**
```
输入："我的信用卡丢了怎么补办？"
     ↓
BERT分类
     ↓
输出：咨询类 → 指向客服机器人

类别体系：查询/办理/投诉/咨询
数据量：每天10万+客服对话
训练周期：2周
效果：替代60%人工客服
```

### 二、命名实体识别（NER）

**用途**：识别文本中的实体（人名、地名、机构名等）

**适用场景**：

| 场景 | 输入 | 输出 | 数据量 |
|------|------|------|--------|
| 新闻抽取 | 新闻文章 | 人名/地名/机构 | 5000+ |
| 病历分析 | 医生病历 | 疾病名/药物名 | 10000+ |
| 简历解析 | 求职简历 | 姓名/学历/公司 | 2000+ |
| 法律文书 | 判决书 | 当事人/法院/案号 | 5000+ |

**案例：财经新闻实体抽取**
```
输入："苹果公司CEO蒂姆·库克在北京宣布，将在中国投资10亿美元建设研发中心。"
     ↓
BERT-NER
     ↓
输出：
苹果公司    → ORG（机构）
蒂姆·库克    → PER（人名）
北京        → LOC（地名）
10亿美元    → MONEY（金额）

应用：构建财经知识图谱
数据：每天5000+篇财经新闻
标注：每篇50元，5000篇约25万元
效果：F1值92%
```

**案例：医疗病历信息抽取**
```
输入："患者张三，男，45岁，主诉头晕头痛3天，既往高血压病史5年，口服硝苯地平控制血压。"
     ↓
BERT-NER（医疗版）
     ↓
输出：
张三        → PATIENT（患者名）
45岁        → AGE（年龄）
头晕头痛    → SYMPTOM（症状）
高血压      → DISEASE（疾病）
硝苯地平    → DRUG（药物）

应用：电子病历结构化
数据：每天5000+病历
标注：医生标注，每条20元，1万条约20万元
效果：准确率94%，节省医生60%录入时间
```

### 五、方案选择总结

| 任务类型 | 最小数据量 | 典型案例 | 是否适合项目别名 |

| 简单分类 | 500-1000 | 情感分析、意图识别 | ❌ |
| NER | 5000-10000 | 新闻抽取、简历解析 | ❌ |

| 语义相似度 | 5000-10000 | 问答匹配、推荐系统 | ❌ |

**结论**：
- 项目别名场景数据产生太慢（每天2条）
- BERT微调需要5000+条数据
- 达到需求需14年积累
- **永远不需要BERT微调**
