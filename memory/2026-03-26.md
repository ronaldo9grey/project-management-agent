## 🔧 问题修复 (2026-03-26 15:00)

### 问题：登录系统报错

**现象**:
- `/vite.svg:1 Failed to load resource: 404`
- `AxiosError: Network Error` - 连接 `127.0.0.1:3000` 被拒绝

**根因**:
1. 前端 `api.ts` 中 API 地址写死为 `http://127.0.0.1:3000`，浏览器访问时指向用户本机
2. `vite.svg` 路径为绝对路径 `/vite.svg`，在 `/agent/` 子路径下部署时404

**修复**:

| 文件 | 修改 |
|------|------|
| `frontend/src/api.ts` | `API_BASE_URL` 改为 `'/agent-api'`（使用Nginx代理） |
| `frontend/index.html` | favicon 路径改为 `/agent/favicon.svg` |
| `frontend/index.html` | manifest 路径改为 `/agent/manifest.json` |

**部署**:
```bash
# 重新构建
cd /home/ubuntu/.openclaw/workspace/project-agent/frontend && npm run build

# 复制到Nginx目录
sudo cp -r dist/* /var/www/project-agent/frontend/
sudo chown -R www-data:www-data /var/www/project-agent/frontend/

# 重载Nginx
sudo nginx -s reload
```

**Nginx 代理配置** (`/etc/nginx/sites-enabled/project-cost-tracking`):
```nginx
# 智能体前端
location /agent {
    alias /var/www/project-agent/frontend/;
    try_files $uri $uri/ /agent/index.html;
}

# 智能体后端API
location /agent-api/ {
    proxy_pass http://127.0.0.1:3000/;
}
```
