### 常用命令
```bash
# 前端构建
cd /var/www/project-cost-tracking/frontend && npm run build

# 后端重启
cd /var/www/project-cost-tracking/backend
source venv/bin/activate
pkill -f "uvicorn.*8000"
nohup uvicorn app.main:app --host 0.0.0.0 --port 8000 > logs/uvicorn.log 2>&1 &

# Nginx 重启
sudo nginx -t && sudo nginx -s reload
```

### 注意事项
- 前端修改后必须执行 `npm run build` 才能生效
- 构建后需同步文件到 `dist/project/` 子目录
- 后端模型变更后需重启 uvicorn 进程
