# 2026-05-24 记忆

## 🔍 看板工时详情弹窗闪烁问题 - 代码审查

### 问题描述
看板页面 → 工时统计（项目维度）→ 点击单元格弹出个人详细工时 → 鼠标移到主页面 → 窗口不断闪烁

### 根因分析

**核心问题：弹窗（position: fixed）渲染在 `.card` 内部，受到卡片 CSS 属性的严重影响**

`Dashboard.tsx` 中 `MonthlyHoursCard` 组件的弹窗直接渲染在 `card-body` 内部：

```jsx
<div className="card-body" style={{ padding: 0 }}>
  {/* 表格内容 */}
  {viewMode === 'project' && projectData && ( ... )}
  
  {/* 弹窗在 card-body 内部！ */}
  {detailModal.show && (
    <div style={{ position: 'fixed', inset: 0, ... }}>
```

**三个致命 CSS 属性：**

#### 1. `.card` 的 `overflow: hidden`（styles.css）
- 弹窗被裁剪到卡片边界内，无法覆盖全视口
- 用户看到的"遮罩"只覆盖卡片区域

#### 2. `.card` 的 `backdrop-filter: blur(24px)`（styles.css）
- **创建新的包含块（containing block）**
- `position: fixed` 的弹窗变成相对于卡片定位，而非视口
- `inset: 0` 只填满卡片区域，不是全屏

#### 3. `.card:hover` 的 `transform: translateY(-2px)`（styles.css）+ `transition: all 0.4s`
- hover 时卡片上移 2px，弹窗随之位移
- **鼠标在卡片边缘时触发震荡循环**：
  - hover → translateY(-2px) → 卡片上移 → 鼠标不再在卡片上 → 取消hover → 卡片下移 → 鼠标又在卡片上 → hover → 循环
  - 配合 0.4s 过渡动画，视觉上就是不断闪烁

### 涉及文件
- `frontend/src/pages/Dashboard.tsx` - MonthlyHoursCard 组件，弹窗渲染位置
- `frontend/src/styles.css` - .card 的 overflow/backdrop-filter/transform

### 修复方案（待万哥确认后再改）
1. **用 React Portal 将弹窗渲染到 document.body**（根治方案）
2. 或给弹窗所在的 card 加特殊 class，覆盖 hover transform
3. 或弹窗打开时给 card 加 className 禁用 hover 效果
