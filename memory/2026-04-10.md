# 2026-04-10 工作记录

## 🔧 系统性重大修复（上午）

### 1. Token刷新无限循环问题（严重）
**问题**：Token刷新接口返回同一个token，导致401错误无限循环，最终PostgreSQL连接池耗尽
**修复**：调用现有后端的refresh接口获取新token
**文件**：`backend/app/main.py` refresh_token函数

### 2. 数据库连接池泄漏（严重）
**问题**：89处`create_engine()`调用，每次创建新连接池，导致连接耗尽
**修复**：
- 创建全局单例连接池模块 `backend/app/database.py`
- 配置：pool_size=10, max_overflow=20, pool_recycle=3600
**影响**：所有后端模块重构使用统一连接池

### 3. 硬编码密码移除
**问题**：数据库密码硬编码在代码中
**修复**：
- 创建 `.env` 文件存储敏感配置
- 更新 systemd 服务从 `.env` 加载环境变量
**文件**：`backend/.env`, `backend/.env.example`

### 4. 缓存TTL机制
**问题**：内存缓存永不过期，持续增长
**修复**：使用 `cachetools.TTLCache` 实现：
- token缓存：8小时
- 用户信息缓存：1小时
- 当前用户缓存：8小时
**文件**：`backend/app/cache.py`（新增）

### 5. 前端错误处理优化
**问题**：错误页面中setTimeout无效，无指数退避
**修复**：
- `safeRedirect` 简化逻辑
- 重试添加指数退避（1.5s → 3s → 6s）
- Token刷新频率降低（30分钟→10分钟）
- 添加 online/offline 事件监听
- Chat API 超时从30s改为60s
**文件**：`frontend/src/api.ts`, `frontend/src/utils/auth.ts`

### 6. Nginx HTTP/2启用
**修复**：`listen 443 ssl http2;`
**效果**：提升性能，避免协议降级问题

### 7. dashboard_service.py 数据库连接未初始化
**问题**：`engine=None` 从未调用 `_get_engine()`
**修复**：所有 `engine.connect()` 替换为 `_get_engine().connect()`
