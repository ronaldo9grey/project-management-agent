### 2. 后端任务分类逻辑修正

修改 `get_my_project_risks` API 的任务分类逻辑：

```sql
-- 任务状态计算
CASE 
  WHEN actual_end_date IS NOT NULL AND actual_end_date > end_date 
  THEN 'delayed_completed'   -- 延期完成
  WHEN actual_end_date IS NOT NULL AND actual_end_date <= end_date 
  THEN 'completed'           -- 按时完成
  WHEN end_date < CURRENT_DATE AND actual_end_date IS NULL 
  THEN 'delayed_ongoing'     -- 已延期未完成
  WHEN start_date IS NOT NULL AND start_date <= CURRENT_DATE 
  THEN 'ongoing'             -- 进行中
  ELSE 'not_started'         -- 未开始
END
```

### 16. Nginx代理配置修复（API 404错误）

**问题**：所有后端API返回404，前端加载成功但无法获取数据

**根因**：Nginx代理配置错误
```
前端请求: /agent-api/api/agent/notifications
错误配置: proxy_pass http://127.0.0.1:3000/api/agent/;
结果路径: http://127.0.0.1:3000/api/agent/api/agent/notifications ❌

正确配置: proxy_pass http://127.0.0.1:3000/;
结果路径: http://127.0.0.1:3000/api/agent/notifications ✅
```

**修复**：
```nginx
location /agent-api/ {
    proxy_pass http://127.0.0.1:3000/;  # 注意结尾是/，不是/api/agent/
    ...
}
```
