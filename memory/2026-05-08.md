## 工作日动态计算（下午修复）

### 问题
- 原方案：硬编码22天
- 用户反馈：
  - 4月应为19天（清明4/6 + 三月三4/17、4/20）
  - 5月应为19天（劳动节1-5日，4/28周日、5/9周六补班）

### 新增模块
**backend/app/holidays.py**

功能：
- 2026年中国法定节假日配置
- 支持调休工作日（周末补班）
- `calculate_working_days(year, month, region)` 函数

### 2026年节假日表

| 节日 | 假期日期 | 调休补班 |
|------|---------|---------|
| 元旦 | 1月1日-3日 | 无 |
| 春节 | 2月17日-23日 | 2/11周日、2/24周六 |
| 清明 | 4月4日-6日 | 无 |
| 广西三月三 | 4月17日-20日 | 无 |
| 劳动节 | 5月1日-5日 | 4/28周日、5/9周六 |
| 端午 | 6月19日-21日 | 无 |
| 中秋 | 9月11日-13日 | 无 |
| 国庆 | 10月1日-7日 | 9/28周日、10/11周六 |

### 2026年各月工作日

| 月份 | 工作日 |
|------|--------|
| 1月 | 20天 |
| 2月 | 15天（春节） |
| 3月 | 22天 |
| 4月 | **19天**（清明+三月三） |
| 5月 | **19天**（劳动节+调休） |
| 6月 | 21天 |
| 7月 | 23天 |
| 8月 | 21天 |
| 9月 | 21天 |
| 10月 | 18天 |
| 11月 | 21天 |
| 12月 | 23天 |

### 计算公式
```python
# 休息日 = (周末 | 节假日) - 调休上班
rest_days = (weekends | holidays_in_month) - workdays_in_month

# 工作日 = 总天数 - 休息日
work_days = all_days - rest_days
```

## 总工时一致性修复

### 问题
- 人员维度：2097.3h
- 项目维度：2095.9h
- 差异：1.4h（浮点数精度）

### 修复方案
**统一精度处理**：
- 所有工时值在累加时立即 `round(hours, 1)`
- 不累积原始精度再统一处理

### 代码修改（routes/stats.py）
```python
hours_rounded = round(hours, 1)
official_hours[project_name]["members"][emp_name] = round(
    official_hours[project_name]["members"].get(emp_name, 0.0) + hours_rounded, 1
)
official_hours[project_name]["total_hours"] = round(
    official_hours[project_name]["total_hours"] + hours_rounded, 1
)
```
